2. 离散化代码本质与频域滞后代价

  • 代码锁存本质：在 C2000 DSP 算法中，I_Term = I_Term_Prev + Ki * Ts * Error。当误差收敛为零时，代码退化为 I_Term = I_Term_Prev，将稳态占空比（如 ）牢牢锁定支撑硬件。
  • 中频段震荡风险：原点极点在全频段恒定贡献 相位滞后。在中频段必须通过 Type II / Type III 补偿器引入超前零点（），将总相位重新拉回至 危险红线以上，确保充足的相位裕度。
