站内阅读导览：电力电子与硬件笔记索引

欢迎访问。这个博客主要整理了我在大功率电力电子与硬件开发过程中积累的专题笔记，内容涵盖变换器拓扑、高频磁元件、环路建模、SiC 驱动与保护、EMC/安规以及测试验证。

如果你时间有限，可以按下面这几个入口快速浏览：

  • 了解个人背景与项目方向：见 关于我 和 工程实践
  • 按专题找具体文章：见 全站技术索引（60 篇完整目录）

按方向推荐几篇代表性笔记

1. 变换器拓扑与软开关

  • LLC 谐振变换器 FHA 增益推导、阻抗分岔与 ZVS 边界核算
  • 双向隔离 DC-DC（PSFB / DAB / CLLC）软开关边界与回流功率分析
  • T 型三电平逆变器 SVPWM 调制、中点电位平衡与损耗分布
  • 有源 PFC 输入谐波抑制、图腾柱无桥架构与 100Hz 纹波环路解耦

2. 驱动保护、控制环路与信号链

  • MOSFET 栅极寄生振荡、共源电感负反馈与退饱和短路保护
  • 高压隔离栅极驱动：自举电荷平衡、CMTI 抗扰与 DESAT 软关断
  • 开关电源状态空间平均建模、Type-II/III 补偿与环路稳定裕度
  • 分流电阻开尔文采样、运放 CMRR 失配误差与 ADC 噪声预算

3. 磁设计、EMC 与测试验证

  • 高频变压器 AP 法几何选型、三明治绕组损耗与气隙核算
  • 大功率开关电源 EMI 频谱表征、差共模解耦与两级滤波器设计
  • 高频磁芯损耗（SE/iGSE）、软磁材料选型与绕组实测解耦
  • 功率半导体双脉冲测试（DPT）杂散电感辨识与对拖温升验证
  • LC/LCL 滤波器特征阻抗、谐振阻尼整定与 50kW 并网算例

如有技术交流或发现笔记里的疏漏，欢迎发邮件至 wenzhenjian-ee@outlook.com，或在 GitHub 联系。
