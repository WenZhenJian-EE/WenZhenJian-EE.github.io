模拟电源控制器架构原理、环路调制与保护机制

模拟 PWM 控制芯片内部硬件单元与工作机理

经典模拟 PWM 控制器（如电压型 TL494/SG3525，电流型 UC3842/43/44/45 及移相全桥 UCC28950）构成了硬件闭环控制的物理基石：

  • 误差放大器 (EA)：将反馈电压 与 高精度带隙基准 比较，输出接至 COMP 引脚供外挂 Type II/III 模拟补偿网络；
  • 时钟振荡器 (OSC)：产生周期性时钟脉冲，送至复位优先 RS 锁存器的置位端（S），触发每个周期的 PWM 开通；
  • PWM 比较器与限流比较器：将 COMP 信号或 内部逐周期过流阈值与采样斜坡比对，送至 RS 锁存器的复位端（R），触发周期内关断；
  • 图腾柱输出级：输出 峰值瞬态驱动电流，直接控制功率管栅极。

电压模式（VMC）与峰值电流模式（PCMC）物理对比

控制信号比较 单一输出电压误差 与芯片内部固定锯齿波比对 电压外环误差 与电感实时上升电流斜坡比对
被控对象系统阶数 二阶 LC 谐振系统（存在共轭双极点 ） 降为一阶系统（电感等效为受控电流源，仅含 单极点）
环路补偿复杂度 高：必须配置 Type III 补偿网络提供 超前相位 低：标准 Type II 补偿网络即可实现大带宽与 相位裕度
抗偏磁与动态响应 慢（受 LC 惯性制约，推挽变压器易偏磁） 极快：输入母线电压扰动在单周期内即刻纠正，天然消除变压器直流偏磁

经典模拟控制器选型实践：TL494 与 SG3525

  • TL494：双误差放大器架构，但输出级为开路三极管（驱动能力较弱，需外挂图腾柱驱动），且无专用死区配置引脚（需靠死区控制端 DTC 外部分压）。
  • SG3525：集成大功率互补图腾柱输出（可以直接驱动大功率 MOSFET 栅极），具备专用放电电阻引脚 精确整定互补死区时间（），且内置软启动电路，是推挽、半桥与全桥变换器的工业级经典首选。
