硬件工程设计手册·总目录与知识架构索引

本手册是作者在电力电子变换器研发、高频磁元件设计、模拟与数字控制环路调试、EMC/安规认证及硬件可靠性工程一线实践中沉淀的完整硬件工程知识体系与实战设计指南。

全书按照工程研发的底层物理逻辑与设计流，划分为 8 大核心知识模块与 60+ 篇深度技术专题。点击对应专题链接即可跳转至详细设计规范与推导。

1. 电力电子基础与核心理论

  • 工程常用计算公式收集：汇集阻抗变换、磁路核算、纹波率与有效值等常用硬件计算闭式解。
  • 数值物理意义与波形数学分析：从微积分与傅里叶级数解析非正弦周期开关波形的有效值、平均值与谐波功率。
  • 源的本质定义与物理理解：深入剖析恒压源、恒流源、受控源与恒功率负载的外特性与交互稳定性。
  • 电路基础底层物理原理：基尔霍夫定律、电荷守恒与能量流动的第一性原理解析。
  • 电力电子基础理论（上）：功率半导体开关行为、能量变换准则与伏秒平衡定理。
  • 电力电子基础理论（下）：电流连续性、换流重叠角与换流回路杂散参数分析。

2. 高频磁元件与磁路设计

  • 高频磁学基础物理量与麦克斯韦方程：磁感应强度 $B$、磁场强度 $H$、磁导率 $\mu$ 与磁滞回线解析。
  • 高频变压器与电感拓扑磁设计全流程：AP 法、Kg 法、绕组分层与磁通密度安全裕度计算。
  • 磁阻网络解析法 (Reluctance Network)：复杂磁路、非对称气隙与漏磁通的等效磁阻拓扑建模。
  • 磁饱和机理、气隙调整与漏感精确控制：气隙对直流偏置能力的拓展与漏感产生机理。
  • 高频磁损耗、绕组结构、材料与测试：Steinmetz 铁损模型、趋肤效应、邻近效应 Dowell 模型与阻抗分析仪测试。
  • 麦克斯韦方程组与变压器等效电路分析：从电磁场到集总参数 $T$ 型与 $\pi$ 型等效电路的数学映射。
  • 磁性材料供应商沟通与工程选型实务：磁芯材质（铁氧体/纳米晶/铁硅铝）选型与飞线绝缘工艺要求。

3. EMC 电磁兼容、安规与可靠性设计

  • 电磁兼容（EMC）物理基础与耦合路径：传导与辐射发射机理、近场电场/磁场天线模型。
  • 开关电源传导 EMI 测试原理与 LISN 物理机制：人工电源网络工作原理、差模与共模噪声分离及滤波器设计。
  • EMC 工程设计案例与整改实录（一）：开关节点振铃吸收、屏蔽层回流与滤波器阻抗失配实战。
  • EMC 工程设计案例与整改实录（二）：雷击浪涌、静电放电（ESD）与电快速瞬变脉冲群（EFT）防护拓扑。
  • 硬件安规设计核心体系与标准解读：绝缘等级划分（基本/补充/双重/加强绝缘）与接地架构。
  • 安规基础物理概念与防护模型：电气间隙（Clearance）、爬电距离（Creepage）与固体绝缘穿透。
  • 国际安规标准收录与深度解读：IEC 62368、IEC 60664-1 与 GB 4943 标准条款工程落地。
  • 安规型式试验与失效案例整改：耐压击穿、绝缘电阻跌落与温升超标排查。
  • 元器件失效物理分析（Failure Analysis）：过电应力（EOS）、静电击穿与热疲劳微观机理。

4. 接地哲学、系统隔离与热设计工程

  • 硬件系统级地线哲学与接地架构：单点接地、多点接地与混合接地的物理边界与地环路切断。
  • 接地策略与地弹抑制详细概念：功率地（PGND）、信号地（AGND/DGND）与保护地（PE）的分区与单点汇流。
  • 系统隔离与接地综合工程设计：电磁隔离、光电隔离与容隔离器件的选型与布局。
  • 传热学基础与热阻等效网络：热传导、热对流与热辐射方程及器件结温 $T_j$ 计算。
  • 电力电子设备风冷散热器设计与计算：散热器型材选型、风阻曲线与风机风量匹配。

5. 模拟控制、运放信号链与采样系统

  • 经典模拟运算电路与运放信号链设计指南：虚短虚断、差分输入阻抗不对称、精密整流与容性负载补偿。
  • 模拟滤波器与运放电路结构拓扑：Sallen-Key、多路反馈（MFB）有源滤波器与相频特性分析。
  • 控制系统零极点稳定性分析：s 域阻尼比、自然振荡频率与波特图相位裕度准则。
  • 模拟反馈环路补偿器设计：Type I、Type II 与 Type III 补偿网络运放实现与参数整定。
  • 离散滤波器与快速解析电路技术 (FACTs)：小信号传递函数的无损快速求解与数字离散化。
  • 驱动与控制芯片内部模拟控制架构剖析：峰值电流模式、平均电流模式与迟滞控制内部逻辑。
  • 精密电压与电流采样硬件设计规范：开尔文采样、差分抗干扰、采样电阻温漂与 ADC 阻抗匹配。

6. 功率半导体、栅极驱动与 PCB 布局

  • 米勒效应、并联均流与开关速度定义：$C_{\mathrm{gd}}$ 寄生耦合、动态导通特性与振荡抑制。
  • 栅极驱动电路与功率管外围电路专题：推挽驱动、自举升压回路与负压关断拓扑。
  • 栅极驱动设计案例与实战分析：SiC/GaN 快开关驱动优化与 CMTI 抑制。
  • 栅极驱动常见故障与异常波形分析：驱动欠压、米勒误导通与振铃过冲整改。
  • 高频开关电源 PCB Layout 黄金法则：最小化高频大电流回路包围面积与敏感信号屏蔽走线。

7. 电力电子拓扑剖析与数字控制系统

  • Buck 与 Boost 变换器工作模态与参数计算：CCM/DCM 边界、纹波电流系数与动态小信号建模。
  • 开关电容与飞跨电容变换器 (Flying Capacitor)：多电平拓扑、电荷再分配损耗与电容均压控制。
  • LLC 谐振变换器深度设计专题：FHA 基波近似分析、电压增益曲线、谐振网络参数计算与 ZVS 边界。
  • 有源功率因数校正 (PFC) 专题：Boost PFC 电流连续/临界模式、乘法器配置与 THD 优化。
  • 移相全桥、DAB 与 CLLC 拓扑剖析：双向功率流动、回流功率抑制与移相角控制。
  • 辅助电源常用拓扑与反激设计：单端反激、准谐振（QR）工作模式与缓冲吸收设计。
  • 逆变器拓扑剖析与调制策略专题：全桥逆变、SPWM 与 SVPWM 空间矢量调制算法。
  • 无线电能传输拓扑专题 (WPT)：磁耦合谐振补偿网络（SS/SP/LCC）与能效优化。
  • ARM 架构微控制器最小系统设计：STM32 晶振、电源去耦、复位与高速外设接口。
  • TI C2000 DSP 最小系统外围电路设计：ADC 供电基准、HRPWM 保护与 CMPSS 窗口比较器应用。
  • CPLD 逻辑控制器最小系统外围设计：硬件状态机、互锁保护与纳秒级故障封波电路。
  • 主流 MCU/DSP 硬件资源对比与选型指南：算力、ADC 采样速率、定时器分辨率与工业生态全景对照。
  • 车载与工业通信：隔离 CAN 收发器外围设计：CAN-FD 物理层隔离、终端匹配与共模扼流圈设计。
  • 4G 远程通信模块外围硬件设计：射频阻抗匹配、瞬态大电流供电与 SIM 卡 ESD 防护。
  • GPS/北斗定位模块外围硬件设计：低噪声放大器（LNA）、无源天线匹配与授时脉冲。

8. 测试调试、故障排查（RCA）与器件案例库

  • 典型硬件故障与炸机事故根本原因分析 (RCA) 实录：高压预充死锁、采样温漂放大与共模地环路死锁排查。
  • 硬件研发实操手记：样机调试流程与避坑指南：带载 SOP、探头接地寄生效应与双向 DCDC 调试。
  • 电路测试波形分析与异常诊断：振铃过冲、体二极管反向恢复与动态饱和压降实测。
  • 电路测试仪器选型与测量技巧：示波器带宽、差分探头校准与 FRA 环路分析仪实战。
  • 机械结构、热传导与硬件装配设计：螺栓扭矩、绝缘垫片导热系数与铜排折弯工艺。
  • 材料物理特性与绝缘耐温基础：FR-4、覆铜板（CCL）介电常数、击穿场强与树脂老化。
