开源项目 (Open Source Projects)

这里展示了我个人自研并开源的两款硬件与电子工程辅助软件。这些软件为硬件设计、信号分析与车载总线调试提供了高效的离线计算与实时可视化解决方案。欢迎在 GitHub 上克隆、贡献或直接下载打包好的 Release 运行程序。

Hardware Engineering Toolbox Desktop

电力电子 / 桌面计算套件

基于 Electron + React 19 + TypeScript + FastAPI 打造的高性能硬件工程计算工作台。内置 30 大工程设计模块、交互式拓扑沙盒与实时波特图仿真引擎，支持离线计算与 SQLite 本地数据持久化：

  • 磁性元件与损耗：变压器/电感协同设计、Dowell 绕组 AC 损耗模型、iGSE 磁芯损耗核算与磁阻网络求解。
  • 拓扑设计与应力：Buck/Flyback 全参数闭环设计、DC-Link 电容纹波电流谱分析与 RCD/RC 吸收电路参数拟合。
  • 控制环路与稳定性：Type II/III 模拟补偿器设计、Bode 图频率特性分析与 Middlebrook 输入阻抗稳定性判据。
  • 热设计与安全标准：Foster 瞬态 RC 热阻网络推演、散热器稳态热仿真与 IEC 60664 爬电绝缘校验。
Electron React 19 TypeScript FastAPI Python 3.11 SQLite

Serial & CAN Bus Debugger V3.0

支持串口 / CAN总线 / 实时示波器调试上位机

支持串口（UART）、CAN / CAN-FD 通信与高频实时示波器调试的现代化工业级上位机。彻底终结传统上位机卡顿与内存泄漏，具备百万级物理点数吞吐能力与原生系统字体极速渲染：

  • 120FPS 丝滑高刷示波：自适应 60~120Hz 高刷刷新，十万点深度环形缓冲，双测量光标即时解算时间差 ΔT、频率 1/ΔT 与电压差 ΔV。
  • 硬件级边沿触发器：内置 Auto、Normal、Single 多模式边沿触发，支持阈值电平与极性捕捉，集成 10 秒故障前后全景黑匣子录波。
  • 总线协议与报文监视：高速串口（最高 921,600 bps）与 CAN/CAN-FD 双模态支持，集成高频虚拟滚动监视器，数据流零丢包。
  • 自定义调试控制矩阵：常驻双列按键与无级调参滑块（内置 80ms 防抖节流），集成 LLC FRA Bode 动态扫频与 FFT 频域分析。
  • 环境自适应双语与零内嵌字体：自动识别操作系统环境呈现英文/中文，0 外挂字体，极速便携单文件 EXE 绿色交付。
Python 3.11 FastAPI WebSocket Vue 3 WebView2 SciPy Cantools
