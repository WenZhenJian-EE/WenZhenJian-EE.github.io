右半平面零点（RHPZ）的物理机理

在 Boost 与 Buck-Boost 拓扑中，当占空比突然增大 时，开关管导通时间延长，导致向输出端输送电能的二极管导通时间缩短。在电感电流爬升至新稳态之前，输出电容被迫单独放电支撑负载，导致输出电压在时域上出现“非极小相位反向跌落”。

  • 频域危害：RHPZ 提供 增益抬升的同时贡献了高达 的急剧相位滞后，构成无法通过超前补偿器抵消的物理带宽硬瓶颈（闭环穿越频率强制限制在 ）。

峰值电流模式控制（PCMC）物理降阶与斜坡补偿

1. 物理降阶效应

电流内环直接伺服电感瞬时电流，在宏观上将储能电感等效为一个受控电流源，二阶 LC 功率级瞬间降阶为一阶 RC 惯性系统，彻底消除了 二阶共振相移，极大简化了电压外环补偿设计。

模拟补偿网络（Type I / II / III）设计准则

  • Type I 补偿器：纯积分器（1 个原点极点），提供 恒定相位滞后，适用于极低频慢环（如 PFC 电压外环）；
  • Type II 补偿器：1 个原点极点 + 1 个零点 + 1 个高频极点，最大提供 相位提升，适用于电流模式等效一阶系统；
  • Type III 补偿器：1 个原点极点 + 2 个零点 + 2 个高频极点，最大提供 强相位提升，适用于电压模式二阶 LC 功率级系统。
