高压电力电子安规设计：绝缘配合、电气间隙与爬电距离精算

基于危险源的安全工程（HBSE）与能量源分级

根据现代国际安规标准（IEC 62368-1 / IEC 60664-1），系统防护基于能量源分级与单点失效容错：

  • ES1 (安全能量源)：（SELV 安全特低电压，人体触碰无生理伤害）；
  • ES2 (临界能量源)：（触碰有痛感但无持续生理伤害，需一层基础防护）；
  • ES3 (危险能量源)：市电 、 高压母线（触碰可致致命电击，必须配置双重绝缘或加强绝缘）。

五大绝缘等级与 Class I / Class II 保护机制

绝缘等级 物理定义与功能边界 击穿耐压强度要求 典型工程实现方式
功能绝缘 (Functional) 仅维持电路正常工作（如防止正负极短路），不提供防电击保护 满足工作电压峰值 走线间距、元器件引脚间距
基本绝缘 (Basic) 第一道防电击物理屏障（假定在生命周期内可能老化失效） 耐受 瞬态工频高压 单层漆包线、绝缘散热垫片
附加绝缘 (Supplementary) 在基本绝缘之外增设的第二道独立物理屏障 耐受 瞬态工频高压 外部塑料绝缘隔离护罩
双重绝缘 (Double) 基本绝缘 + 附加绝缘 两层独立屏障物理叠加 耐受 两层独立绝缘套管
加强绝缘 (Reinforced) 单一绝缘物理实体，但具备等效于双重绝缘的抗电击击穿能力 耐受 变压器三层绝缘线、高压磁耦数字隔离芯片

Class I 设备的“PE 强接地保命法则”

在金属机箱工业设备中，高压带电体与金属外壳之间做基本绝缘，同时金属外壳必须通过低阻抗螺栓硬连接至保护地（PE）。一旦基本绝缘老化击穿，高压电流直接通过 PE 大电流泄放，迫使前端断路器在数十毫秒内跳闸，切断危险电源。

电气间隙（Clearance）与爬电距离（Creepage）查表精算

  • 电气间隙 (Clearance)：两个导体穿透空间空气的最短直线空间距离（防止瞬态过电压脉冲击穿空气引发电弧放电）；
  • 爬电距离 (Creepage)：两个导体沿固体绝缘介质表面的最短物理轮廓距离（防止高压在潮湿积尘环境下产生表面漏电起痕炭化通路）。

PCB 开槽物理隔离与固体介质厚度规范

  • 物理隔离构型：高压原边（ES3）与安全副边（SELV）之间设置 PCB 物理铣空槽（槽宽 ）。
  1. 开槽打破爬电：在原副边隔离带开铣宽度 的通槽，强行截断表面漏电通道，将爬电距离转化为空间电气间隙；
  2. 严禁信号跨槽走线：隔离槽切断了内层地回流平面，严禁在开槽区域上方跨线，跨隔离通信必须选用专用磁耦/光耦芯片；
