DSP C2000 最小系统硬件设计与 ePWM/ADC 实时联动机制

C2000 架构选型与命名法则

在数字电源、逆变器与电机 FOC 伺服系统中，TI C2000 系列微控制器（如 F28P65x、F28004x、F2837xD）是实时控制的核心底座：

  • 系列与功能安全：659 支持硬件锁步（Lockstep）与 SIL-3 / ASIL-D 功能安全；650 集成 EtherCAT 与多路 CAN-FD，适用于工业与储能控制。
  • 双核/单核配置：D 代表双 C28x 主核（配备 CLA 并行协处理器）；S 代表单核。
  • 高集成度模拟外设：单片集成多达 36 路高速 12/16 位 SAR ADC、高精度 ePWM（HRPWM 分辨率达 150ps）、片上 CMPSS 比较器子系统（响应时间 ，直接触发 ePWM 硬件封波保护）以及 X-BAR 跨总线硬件互联矩阵。

JTAG 调试接口设计与固件锁死救砖机制

1. JTAG 硬件信号端接与抗扰

  • TCK（测试时钟）：在 MCU 侧引脚预留 下拉电阻，防止高频开关噪声感应导致时钟误触发掉线。
  • TMS（模式选择）：外部并联 上拉至 VDDIO，确保未插仿真器时 TAP 状态机稳定锁死在 Test-Logic-Reset 状态。
  • TDI / TRST：TDI 弱上拉，TRST 外部配置 下拉电阻确保上电可靠复位。
  • TDO：推挽输出，严禁外接上下拉。

2. 误刷锁死与 Wait Boot 救砖物理流程

当固件意外配置错误时钟锁相环（PLL 超频锁死）或 GPIO 冲突导致调试器无法握手时：

  1. 硬件切换至 Wait-in-Reset 模式：通过硬件引脚（Boot Mode Pins 如 GPIO24/GPIO32）配置为“Wait Boot”或“Boot to SARAM”状态；
  2. 上电复位挂起：芯片上电后 CPU 强制在 ROM 循环等待，不执行 Flash 内的错误代码；
  3. 仿真器重获控制权：CCS 强制连接芯片，执行 Mass Erase 全片擦除，彻底解除死锁。

ePWM 与 ADC 实时联动时序与采样点物理法则

在增减对称计数模式（Up-Down Count）下，ADC 触发时刻与影子寄存器装载时序直接决定了控制环路的相位裕量与噪声抗扰度：

1. 波谷采样（CTR=ZERO）与波峰采样（CTR=PRD）

采样策略 触发时刻 信号物理特征 典型应用领域
波谷采样 (CTR=ZERO) PWM 周期起点/终点 开关管动作间隙，开关斩波噪声最小，信号精确对应电感电流周期平均值 电压电流双闭环、FOC 矢量控制的黄金标准
波峰采样 (CTR=PRD) PWM 周期中心对称点 开关管稳态导通，信号对应电感电流瞬时峰值 峰值电流模式控制（PCMC）、逐周期动态限流

2. 双更新 PWM 模式（Double-Update Mode）与控制延迟减半

在中心对齐 PWM 模式下，在一个开关周期内分别在波峰和波谷触发两次中断并更新占空比：

  • 控制延迟减半：从采样到 PWM 生效的平均控制延迟从一个完整周期 压缩至半个周期 。
  • 频域相位滞后改善：控制延迟引起的相位滞后满足 ，延迟减半直接提升了系统在高频处的相位裕量，允许控制器设置更高的比例积分（PI）增益，显著拓宽闭环控制带宽而不诱发振荡。

电源去耦、晶振布局与模拟基准（VREF）设计

  1. 核电压（VDD 1.2V）与 IO 电压（VDDIO 3.3V）去耦：
    每个电源引脚对必须就近配置 0402 贴片陶瓷电容（距离引脚 ），大容量储能电容布置在板级外侧。
  2. 模拟基准电压（VREFHI / VREFLO）开尔文连接：
    ADC 转换精度完全取决于基准电压源的纯净度。VREFHI 引脚必须紧贴芯片配置 低 ESR 陶瓷电容，VREFLO 必须以独立开尔文地线直接引回模拟地星型汇聚点，严禁接入任何数字地回流。
